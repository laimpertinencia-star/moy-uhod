# Помощник в MVP

## Сейчас

- Локальный режим использует каталог, статусы, корзину, профиль и сохранённую рутину для ответов о выборе крема, замене сыворотки и плане на сегодня. Он показывает пробелы в данных и не выдумывает покупки.
- Онлайн-режим развёрнут на Cloudflare Workers AI с бесплатной дневной квотой. Он отвечает на свободные вопросы по переданному контексту и краткому справочнику с ссылками на American Academy of Dermatology. Живого веб-поиска и общей базы всех косметических средств пока нет.
- Перед внешним запросом нужны два независимых решения: согласие на отправку текста вопроса и согласие на контекст косметички. Каждый конкретный запрос подтверждается ещё раз. Фото не передаются.
- Старые согласия для OpenAI не действуют для Cloudflare. При недоступности сервиса приложение показывает локальную подсказку.

## Для выпуска онлайн-режима

1. Cloudflare Workers AI развёрнут. Адрес записан в `assistant-service-config.js`.
2. Пересобрать и опубликовать обе версии сайта при изменении кода.
3. До приглашения подруг заполнить реального оператора и контакт в документах согласия и проверить применимые требования к обработке данных.

Код платного OpenAI API из старой экспериментальной папки не используется и не входит в публичную сборку.
