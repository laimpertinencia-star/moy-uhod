# Поиск цен для заканчивающихся средств

Статус: проектное решение, **автоматический поиск скидок ещё не подключён**.

## Как должен работать сценарий

1. Пользователь сам указывает остаток средства и отдельно включает отслеживание цен. Неизвестный остаток не считаем низким.
2. При остатке ниже заданного порога приложение сохраняет точное название, вариант, объём и при наличии штрихкод. Пользователь подтверждает карточку товара на одной или нескольких площадках. Похожее название не означает тот же товар.
3. Серверная задача запускается не чаще одного раза в сутки и обращается только к разрешённому источнику цен конкретной площадки. Запросы из телефона при закрытом приложении не запускаются.
4. Сравниваем цену с предыдущей зафиксированной ценой того же предложения и честно указываем дату, продавца, доставку и условия акции. «Скидку» не выводим только по зачёркнутой цене площадки.
5. Уведомляем лишь об изменении, которое прошло фильтр пользователя. Никаких автоматических покупок.

## Что нужно до включения

- Проверить условия доступа и права на использование цен для выбранных маркетплейсов. Открытые API продавца могут показывать **цены собственного магазина**, а не весь каталог покупателей. Например, документация API Яндекс Маркета для продавцов описывает цены товаров конкретного магазина и требует доступ `pricing:read-only`: https://yandex.ru/dev/market/partner-api/doc/ru/reference/prices/getPrices . Такой API сам по себе не решает поиск скидок по всему рынку.
- Выбрать источник с легальным доступом к потребительским предложениям или заключить партнёрское соглашение. Не строить сервис на скрытом парсинге страниц и обходе ограничений.
- Согласовать хранение минимального списка отслеживаемых товаров и подписок на уведомления. Фото и профиль ухода для проверки цен не нужны.
- Добавить защищённую серверную базу для подписок и цен, периодическую задачу и настоящие Web Push. Статическая страница GitHub Pages этого не выполняет.

## Первая реалистичная версия

Кнопка «Искать цену» в карточке заканчивающегося продукта открывает обычный поиск по точному названию на выбранной площадке. Пользователь сам проверяет совпадение и цену. Автоматический мониторинг добавляем после проверки источников данных и настройки сервера.
