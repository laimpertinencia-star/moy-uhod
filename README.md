# Мой уход — планер косметички

Веб-приложение на HTML, CSS и JavaScript в одном файле `index.html`. Это тестовая версия, её пробуют подружки.

**Открыть:** https://laimpertinencia-star.github.io/moy-uhod/

## Что умеет

1. Сфотографировать упаковку и проверить распознанное название (OCR в браузере).
2. Указать зону, тип и время использования каждого средства.
3. Собрать черновик утренних и вечерних шагов и добавить их в рутину.
4. Отмечать выполненное, вести корзину и дневник.

Все данные хранятся только в браузере на устройстве. На сервер они не отправляются, поэтому у каждой своя косметичка, а на другом телефоне или в другом браузере она будет пустой.

## Тильда

Тильда показывает приложение с GitHub Pages через iframe. Код для блока T123 лежит в `tilda/T123-iframe.html`. После правок в `index.html` страница на Тильде обновляется сама, вставлять код заново не нужно.

## Ограничения прототипа

- Помощник и разбор INCI работают по встроенным правилам, нейросеть не подключена.
- Название и штрихкод нужно проверять вручную, внешней базы косметики нет.
- Синхронизации между устройствами нет.
- Приложение не заменяет консультацию врача или косметолога.
