# Мой уход — тестовая версия

Пустая тестовая версия приложения для тестирования. При первом открытии пользователь создаёт косметичку и рутину. Личные продукты, фотографии, история и расписание автора в эту публичную сборку не входят. [Открыть приложение](https://laimpertinencia-star.github.io/moy-uhod/).

## Что умеет

- Сканировать упаковку и помогать проверять распознанное название.
- Собирать черновик рутины из подтверждённых продуктов.
- Вести отметки, корзину будущих покупок и заметки.
- Разбирать состав по встроенным правилам. Неизвестные данные не додумываются.

Данные библиотеки сохраняются в браузере устройства. При первом запуске открывается отдельное окно согласий. Обязательное согласие на локальное сохранение пустое до действия пользователя; внешние согласия выключены. Веб-поиск можно включить только после настройки защищённого сервера и согласия; каждый вопрос подтверждается отдельно. Дополнительный контекст библиотеки и рутины требует отдельной отметки. В ответе показываются источники; помощник не меняет рутину автоматически.

## Веб-поиск

Код бесплатного онлайн-помощника находится в [`assistant-worker-free/`](assistant-worker-free/README.md). Сервис развёрнут на Cloudflare Workers AI. Для отправки каждого вопроса нужны отдельное согласие и подтверждение; живого веб-поиска нет. Если бесплатная квота исчерпана или связи нет, приложение отвечает локально по данным косметички.

Перед приглашением участников тестирования заполните поля оператора и контакта в [`privacy.html`](privacy.html), [`consent.html`](consent.html) и [`terms.html`](terms.html). Сейчас это документы-заготовки, а не подтверждение готовности к публичному тесту. Для тестирования в России отдельно проверьте обязанности оператора, локализацию и трансграничную передачу персональных данных. Согласие в интерфейсе само по себе не подтверждает соблюдение всех требований.

Личная заполненная версия не хранится в этом репозитории; она опубликована отдельно. Данные, которые пользователь добавляет в тестовую версию, сохраняются в браузере его устройства. Помощник не ставит диагноз, не выводит концентрации ингредиентов из одного списка INCI и не заменяет консультацию врача.
