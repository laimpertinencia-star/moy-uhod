Политика обработки данных

Черновик для тестирования. До приглашения тестировщиков оператор обязан заменить поля в квадратных скобках на свои данные и проверить документ с юристом. Пока поля не заполнены, не собирай данные подруг через приложение.

Оператор: [указать полное имя или наименование оператора].
Связь по вопросам данных: [указать email или иной контакт].
Дата и версия: 28 октября 2026 г., версия 2.0.

Какие данные и для чего обрабатываются

Приложение помогает вести личный список косметики, шаги рутины, отметки выполнения, корзину и заметки. Введённые пользователем сведения сохраняются локально в хранилище браузера на устройстве. Приложение не создаёт аккаунт и не синхронизирует данные между устройствами. Не указывай имя, адрес, телефон, медицинские документы и иные сведения, не нужные для ухода.

Фотографии упаковки и состава обрабатываются в браузере для распознавания текста; сами фотографии приложением не отправляются на сервер помощника. Для распознавания браузер загружает код и языковую модель OCR с jsDelivr. Шрифты загружаются с Google Fonts, если браузер не использует локальные системные шрифты.

Внешний помощник — только по отдельному выбору

Веб-поиск выключен по умолчанию. Если пользователь отдельно разрешил его и подтвердил конкретный вопрос, текст вопроса передаётся через серверный посредник в OpenAI API. Данные библиотеки, выбранные продукты и шаги рутины добавляются только при отдельном согласии на контекст и только если относятся к запросу. Фото, профиль и дневник целиком не отправляются. Сервер ограничивает запросы, не пишет содержание запросов в собственные журналы и не содержит ключа в браузере. Технические сведения, включая IP-адрес и заголовки запроса, могут обрабатываться хостингом сервера и поставщиком API.

OpenAI описывает обработку данных API в документации Data Controls. Условия хранения зависят от действующих настроек и исключений поставщика. Уже переданный вопрос приложение удалить у поставщика не может. Ссылки на ответы ведут к внешним сайтам, у которых собственные правила обработки данных.

Срок хранения и удаление

Данные в приложении хранятся в браузере до очистки данных сайта, удаления записей пользователем или удаления профиля браузера. Сделай экспорт резервной копии перед очисткой. Чтобы отозвать разрешение внешнему помощнику, открой раздел «Помощник» → настройки приватности и выключи соответствующие пункты. Отзыв действует на будущие запросы и не отменяет уже состоявшуюся обработку.

Права и обращение

Запросы на доступ, исправление, удаление или отзыв согласия направляй оператору по контакту выше. Оператор отвечает в срок, установленный применимым законодательством. Для публикации тестовой версии оператор отдельно проверяет обязанности по уведомлению надзорного органа, локализации, трансграничной передаче и защите данных в юрисдикциях пользователей.

Обработка может зависеть от GitHub Pages, Cloudflare Workers, OpenAI API, Google Fonts и jsDelivr. До публичного теста оператор должен проверить их актуальные условия, места обработки, договорные основания и применимые требования. Эта страница — техническая заготовка, а не заключение о соблюдении закона.
