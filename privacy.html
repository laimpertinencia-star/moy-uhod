Какие данные и для чего обрабатываются

Приложение помогает вести личный список косметики, шаги рутины, отметки выполнения, корзину и заметки. В тестовой версии введённые сведения сохраняются локально в браузере. В личной версии пользователь может отдельно согласиться на синхронизацию между устройствами через Yandex Cloud; без этой отметки данные остаются на текущем устройстве. Не указывай имя, адрес, телефон, медицинские документы и иные сведения, не нужные для ухода.

Фотографии упаковки и состава обрабатываются в браузере для распознавания текста; сами фотографии приложением не отправляются на сервер помощника. Для распознавания браузер загружает код и языковую модель OCR с jsDelivr. Шрифты загружаются с Google Fonts, если браузер не использует локальные системные шрифты.

Личная версия: облачная синхронизация по отдельному согласию

Если пользователь отдельно отмечает согласие в личной версии, названия и статусы средств, корзина будущих покупок, рутина, отметки выполнения, записи дневника и фотографии карточек синхронизируются в закрытом облачном хранилище Yandex Cloud в регионе ru-central1. Доступ к странице и объектам закрыт для остальных аккаунтов. Ответы анкеты и история переписки с помощником не синхронизируются. Передача начинается только после входа и согласия. Синхронизацию можно выключить в настройках согласий; облачную копию следует отдельно удалить через приложение или запрос оператору. Эта функция требует настройки до реального использования.

Онлайн-помощник по отдельному согласию

Онлайн-помощник выключен по умолчанию. Если пользователь отдельно разрешил внешний ИИ и подтвердил конкретный вопрос, текст вопроса передаётся в Cloudflare Workers AI. Профиль, названия и статусы продуктов, подтверждённые составы, корзина и шаги рутины добавляются только при втором отдельном согласии. При вопросе о реакции могут передаваться недавние отметки применения. Фотографии не отправляются. Помощник использует краткий справочник со ссылками, без живого поиска по интернету и без полной базы товаров.

Приложение хранит историю чата в браузере пользователя и не записывает содержание запросов в серверные журналы. Cloudflare обрабатывает текст запроса и технические данные соединения. По документации Cloudflare стандартные запросы Workers AI не используются для обучения моделей; обработка и возможные исключения описаны у поставщика. Отзыв согласия прекращает будущую передачу, но не отменяет уже состоявшуюся обработку.

Срок хранения и удаление

Данные в приложении хранятся в браузере до очистки данных сайта, удаления записей пользователем или удаления профиля браузера; личная облачная копия хранится до её удаления пользователем или оператором по запросу. Сделай экспорт резервной копии перед очисткой. Чтобы отозвать разрешение внешнему помощнику, открой раздел «Помощник» → настройки приватности и выключи соответствующие пункты. Отзыв действует на будущие запросы и не отменяет уже состоявшуюся обработку.

Права и обращение

Запросы на доступ, исправление, удаление или отзыв согласия направляй оператору по контакту выше. Оператор отвечает в срок, установленный применимым законодательством. Для публикации тестовой версии оператор отдельно проверяет обязанности по уведомлению надзорного органа, локализации, трансграничной передаче и защите данных в юрисдикциях пользователей.

Обработка тестовой версии может зависеть от GitHub Pages, Cloudflare Workers AI, Google Fonts и jsDelivr; личной версии — от Yandex Cloud. До публичного теста оператор должен проверить их актуальные условия, места обработки, договорные основания и применимые требования. Эта страница — техническая заготовка, а не заключение о соблюдении закона.
