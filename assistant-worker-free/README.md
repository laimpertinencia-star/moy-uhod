# Бесплатный онлайн-помощник

Cloudflare Workers AI, модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. В Worker нет OpenAI API, платных ключей, хранения переписки и живого интернет-поиска. Он получает только текст конкретного подтверждённого вопроса и тот контекст, который пользователь отдельно разрешил отправить.

Сервис развёрнут по адресу `https://moy-uhod-free-assistant.assistant-worker-free.workers.dev/v1/chat/completions`. Адрес указан в `assistant-service-config.js`. Для обновления кода Worker из этой папки: `wrangler deploy`; затем пересобрать и опубликовать обе версии сайта при изменении клиентского кода.

Free план имеет дневную квоту; при исчерпании сервис вернёт ошибку, а приложение покажет локальную подсказку. Перед тестированием заполнить реквизиты оператора и контакт в документах согласия, проверить применимые требования к обработке данных и убедиться, что аккаунт остаётся на Workers Free. Не включать платный план без отдельного решения владельца.
