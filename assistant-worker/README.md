# Интернет-поиск помощника

Этот небольшой Cloudflare Worker — защищённый посредник между статическим приложением и OpenAI Responses API. Браузер никогда не получает API-ключ. Worker запускает веб-поиск и добавляет найденные источники в ответ.

## Самая простая настройка на Mac

Дважды щёлкни `Подключить веб-помощника.command` (если macOS предупредит, выбери «Открыть» в контекстном меню). Скрипт откроет вход Cloudflare, затем попросит вставить API-ключ в скрытое поле и развернёт Worker. Ключ передаётся через команду Cloudflare и не сохраняется в проекте.

После развёртывания скопируй показанный адрес `workers.dev`, допиши `/v1/chat/completions` и вставь полный адрес в настройках помощника. Не присылай API-ключ в чат.

## Ручная настройка

1. Создай отдельный проект/ключ API для приложения и настрой в OpenAI Platform бюджетные уведомления и мониторинг расходов. Ключ не отправляй в чат и не добавляй в файлы проекта.
2. Установи Node.js на Mac, открой Terminal в папке `assistant-worker` и выполни `npx wrangler login`.
3. В `wrangler.jsonc` проверь список `ALLOWED_ORIGINS`: там должны быть точные origin сайта и локального адреса (без пути и завершающего `/`). Замени `namespace_id` на уникальное целое число для своего аккаунта Cloudflare. Ограничение запросов приблизительное и применяется на площадках Cloudflare отдельно; оно защищает от случайных всплесков, но не заменяет авторизацию.
4. Установи секрет командой `npx wrangler secret put OPENAI_API_KEY` и вставь ключ в скрытый ввод терминала.
5. Разверни Worker командой `npx wrangler deploy`. Сохрани выданный адрес вида `https://moy-uhod-assistant.<аккаунт>.workers.dev`.
6. Если origin менялись, обнови `ALLOWED_ORIGINS` в `wrangler.jsonc` и разверни Worker снова. Не добавляй `*`.
7. В приложении открой «Помощник» → «Настроить веб-поиск и приватность». Вставь адрес Worker с суффиксом `/v1/chat/completions` и сохрани его. На первом запуске обязательное согласие на локальное сохранение и два необязательных согласия помощнику показываются отдельно; оба необязательных флажка изначально пусты. Каждый сетевой вопрос подтверждается отдельно.

Приложение проверяет HTTPS и `Origin`; Worker ограничивает разрешённые origin, размер запроса и частоту обращений. Ответы с веб-поиском должны содержать ссылки на источники. Если поиск не сработал, интерфейс не выдаёт локальный ответ за результат поиска.

## Данные и границы

- Worker не журналирует текст запроса и посылает провайдеру только сообщение пользователя и контекст, который приложение отобрало по типу вопроса и согласию.
- В настройках приложения нужно сообщить, что запрос передаётся OpenAI API. По документации OpenAI API данные по умолчанию не идут на обучение; журналы предотвращения злоупотреблений могут храниться до 30 дней. Проверь актуальные условия своего аккаунта перед подключением.
- Для тестировщиков в России перед публичным запуском отдельно проверь, кто выступает оператором и как применяются требования 152-ФЗ о локализации и трансграничной передаче данных. Действующая редакция закона ограничивает обработку персональных данных граждан РФ в зарубежных базах при первичном сборе, с предусмотренными законом исключениями; трансграничная передача регулируется отдельно. Одного чекбокса в приложении недостаточно, чтобы подтвердить соответствие. [Статья 18 закона](https://www.consultant.ru/document/Cons_doc_LAW_61801/cbf4e15b7c330f9372e876cdf2bc928bad7950ef/), [пояснение Минцифры о поправках 2025 года](https://www.consultant.ru/document/cons_doc_LAW_511584/).
- До приглашения участников тестирования заполни `[оператор]` и `[контакт]` в согласии, политике и правилах. Сейчас эти документы — черновики. Согласие на обработку персональных данных должно быть конкретным и однозначным; закон требует оформлять его отдельно от иных сведений/документов. Приложение поэтому не отмечает флажки заранее. [Статья 9 закона](https://www.consultant.ru/document/Cons_doc_LAW_61801/6c94959bc017ac80140621762d2ac59f6006b08c/).
- Веб-источники могут ошибаться, рекламировать продукт или устареть. Помощник должен объяснять неопределённость, не диагностировать и не менять рутину автоматически.
- Перед тем как открыть endpoint подружкам, настрой бюджет/лимиты API, проверь список разрешённых origin и помни: CORS не заменяет вход пользователя. Rate limit по IP приблизительный; публичному тесту с большим числом людей позднее понадобится Turnstile или авторизация.

Документация: [OpenAI Web Search](https://developers.openai.com/api/docs/guides/tools-web-search), [OpenAI Data Controls](https://developers.openai.com/api/docs/guides/your-data), [Cloudflare Worker secrets](https://developers.cloudflare.com/workers/configuration/secrets/), [Cloudflare rate limits](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/).
